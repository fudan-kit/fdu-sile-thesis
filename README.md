# 复旦大学硕博士毕业设计论文SILE模板

## 什么是SILE排版语言
SILE (Simon's Improved Layout Engine) 是一个现代的排版系统，旨在产生精美的打印文档。
它与Tex有相似之处，从TeX借用了某些概念和算法，但它并不是TeX家族的派生物。SILE 是从头开始使用现代技术编写的全新的排版和布局引擎，并从图形系统如InDesign中借鉴了一些想法。
主要使用的编程语言是Lua，它允许用户通过高级编程语言轻松扩展排版系统。

## 使用方法
1. 参考[Github文档](https://github.com/sile-typesetter/sile)，安装SILE;
2. 将项目下载到自己编译的目录下；
3. 对多个章节进行修改；
4. 运行`sile compile paper.sil`
